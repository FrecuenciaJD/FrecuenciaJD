# FrecuenciaJD - Emprendimiento Digital

Aplicación web y portafolio profesional para el estudio de voz, doblaje y adaptación musical FrecuenciaJD.

## Características
- Catálogo de servicios vocales e interpretación.
- Asistente Virtual con IA para cotización de proyectos.
- Formulario de contacto directo con validación.
- Panel de Administración con clave para gestión interna.
